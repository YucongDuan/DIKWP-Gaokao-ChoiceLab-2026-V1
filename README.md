# DIKWP Gaokao ChoiceLab 2026 V1

Standalone, offline-first decision-support prototype for 2026 Chinese Gaokao university and major selection.

## Core workflow

Province rule → official data ledger → hard eligibility → rank risk bands → major semantic fit → AI future scenarios → university-major trade-off → professional-group adjustment risk → volunteer list → family consensus → charter verification → Choice Passport.

## Quick start

Open `index.html` in a modern browser. No server, account, API key, or network is required.

The built-in university, ranking, and plan data are synthetic. For real use, import a CSV based on `data/programs_official_template.csv` using only official 2026 provincial examination authority and university sources.

## Non-negotiable boundaries

- No admission guarantee or exact admission probability.
- No automatic final decision.
- No use of third-party rankings as official admission data.
- No replacement for provincial examination authority instructions or university admissions charters.
- Student agency is required; parent preferences cannot silently replace student purpose.
- AI future analysis is scenario planning, not employment or salary prediction.

## Main modules

- student and family profile
- province admission mode
- 2026 official data ledger
- hard eligibility and withdrawal risk
- rank-based reach/target/safe bands
- major semantics and AI change matrix
- professional-group adjustment red lines
- volunteer-list builder
- family consensus board
- charter verification
- 72-hour action plan
- Choice Passport and audit export
